# Görüntü ve video

[Örneklere dön](../../../README_tr.md)

Görüntüleri referans, yerleşim ve karşılaştırma; videoyu zamansal analiz için kullanın. Dosyaları saklayın ve her girdinin rolünü belirtin. Çekim çözümlemesinde görsel analiz, ses dökümü ve son tabloyu ayırın. El kitabındaki akış OpenCV, PyAV ve faster-whisper kullanır. Büyük videolar için Files API gereksinimini tablodan belirleyin.

| Girdi | Sınır |
|---|---|
| Görüntü | 10 MB |
| URL veya base64 video | 50 MB |
| İstek gövdesi | 64 MB |
| Files API ile video | 512 MB |
