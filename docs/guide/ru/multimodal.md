# Изображения и видео

[Вернуться к примерам](../../../README_ru.md)

Используйте изображения для референсов, макетов и сравнений, а видео — для временного анализа. Сохраняйте файлы и указывайте назначение каждого входа. При разборе фильма разделяйте анализ кадров, расшифровку звука и итоговую таблицу. В руководстве используются OpenCV, PyAV и faster-whisper. Ограничения таблицы показывают, когда большому видео нужна Files API.

| Вход | Ограничение |
|---|---|
| Изображение | 10 MB |
| Видео по URL или base64 | 50 MB |
| Тело запроса | 64 MB |
| Видео через Files API | 512 MB |
