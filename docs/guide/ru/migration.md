# Переход с M3 и Preview

[Вернуться к примерам](../../../README_ru.md)

Текущая официальная документация использует MiniMax-M3.1-Flash. Сохраняйте MiniMax-M3.1-Flash-Preview в исходных промптах и записях руководства, обновляя новые настройки. Уберите отключение рассуждений и none. Для OpenAI читайте reasoning_content и итоговый текст из content; не запрашивайте reasoning_split=false. В диалогах с инструментами сохраняйте полные сообщения ассистента и соответствующие результаты.
