# Контекст и кеширование

[Вернуться к примерам](../../../README_ru.md)

Окно контекста составляет 1,000,000 токенов. Организуйте длинный проект со стабильными инструкциями, списком инструментов и повторно используемыми материалами. Автоматический кеш распознаёт повторяющийся контекст. Сохраняйте неизменившееся содержимое и проверяйте поля использования кеша. Управляйте контекстом и выходным бюджетом отдельно.

| Протокол | Использование кеша |
|---|---|
| Anthropic | `usage.cache_read_input_tokens` |
| OpenAI Chat Completions | `usage.prompt_tokens_details.cached_tokens` |
