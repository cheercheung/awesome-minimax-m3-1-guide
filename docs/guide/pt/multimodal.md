# Imagens e vídeo

[Voltar aos casos](../../../README_pt.md)

Use imagens para referências, layouts e comparações, e vídeo para análise temporal. Preserve os arquivos e identifique a função de cada entrada. No detalhamento de planos, separe análise visual, transcrição e planilha final. O manual usa OpenCV, PyAV e faster-whisper. A tabela indica quando vídeos grandes precisam da Files API.

| Entrada | Limite |
|---|---|
| Imagem | 10 MB |
| Vídeo por URL ou base64 | 50 MB |
| Corpo da solicitação | 64 MB |
| Vídeo pela Files API | 512 MB |
