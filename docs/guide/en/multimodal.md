# Images and video

[Back to cases](../../../README.md)

Use image input for references, layouts and comparisons, and video input for temporal analysis. Keep the original files and identify what each input should explain. For a shot breakdown, separate visual analysis, audio transcription and the final spreadsheet. OpenCV, PyAV and faster-whisper are tools used in the handbook workflow. The file limits below determine whether a large video needs the Files API.

| Input | Limit |
|---|---|
| Image | 10 MB |
| Video by URL or base64 | 50 MB |
| Request body | 64 MB |
| Video through Files API | 512 MB |
