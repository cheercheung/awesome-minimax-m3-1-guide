# A task-to-deliverable workflow

[Back to cases](../../../README.md)

Define the result and constraints. Inspect the supplied project, manifests and actual files. Produce a working artifact, then run checks that match the user's task. Repeat measurements with the same inputs and settings. Deliver the artifact together with concise evidence of what was checked. Flowdesk demonstrates this sequence with performance traces and repeated measurements; the options-risk case combines inputs, calculations, a workbook and a memo.


1. Specify inputs and deliverables
2. Inspect actual files
3. Implement the artifact
4. Validate under matching conditions
5. Deliver results and evidence
