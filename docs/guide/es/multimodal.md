# Imágenes y vídeo

[Volver a los casos](../../../README_es.md)

Usa imágenes para referencias, diseños y comparaciones, y vídeo para análisis temporales. Conserva los archivos e identifica su función. En un desglose de planos, separa análisis visual, transcripción y hoja final. El flujo del manual utiliza OpenCV, PyAV y faster-whisper. Los límites de la tabla indican cuándo un vídeo grande necesita Files API.

| Entrada | Límite |
|---|---|
| Imagen | 10 MB |
| Vídeo por URL o base64 | 50 MB |
| Cuerpo de la solicitud | 64 MB |
| Vídeo mediante Files API | 512 MB |
