# Von M3 und Preview migrieren

[Zurück zu den Fällen](../../../README_de.md)

Die aktuelle Dokumentation verwendet MiniMax-M3.1-Flash. Lassen Sie MiniMax-M3.1-Flash-Preview in ursprünglichen Prompts und Handbuchaufzeichnungen stehen und aktualisieren Sie neue Konfigurationen. Entfernen Sie Versuche, das Denken abzuschalten oder none zu setzen. Lesen Sie bei OpenAI reasoning_content und den Antworttext aus content; fordern Sie kein reasoning_split=false an. Erhalten Sie vollständige Nachrichten und Werkzeugergebnisse.
