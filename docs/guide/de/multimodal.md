# Bilder und Video

[Zurück zu den Fällen](../../../README_de.md)

Nutzen Sie Bilder für Referenzen, Layouts und Vergleiche sowie Video für zeitliche Analysen. Bewahren Sie die Dateien und benennen Sie ihren Zweck. Trennen Sie bei der Einstellungsanalyse Bildauswertung, Transkription und Ergebnistabelle. Der Handbuchablauf verwendet OpenCV, PyAV und faster-whisper. Die Tabelle zeigt, wann große Videos die Files API benötigen.

| Eingabe | Grenze |
|---|---|
| Bild | 10 MB |
| Video per URL oder base64 | 50 MB |
| Anfragetext | 64 MB |
| Video über Files API | 512 MB |
