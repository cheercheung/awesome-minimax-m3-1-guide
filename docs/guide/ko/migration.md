# M3 및 Preview에서 이전

[사례로 돌아가기](../../../README_ko.md)

현재 공식 문서는 MiniMax-M3.1-Flash를 사용합니다. 설명서의 원본 프롬프트와 기록에서는 MiniMax-M3.1-Flash-Preview를 유지하고 새 설정을 갱신합니다. 사고를 끄는 설정과 none은 제거합니다. OpenAI 호환 응답은 reasoning_content와 최종 답변 content를 읽고 reasoning_split=false를 요청하지 않습니다. 도구 대화에서는 전체 어시스턴트 메시지와 대응 결과를 보존합니다.
