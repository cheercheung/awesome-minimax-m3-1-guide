# タスクから成果物まで

[事例に戻る](../../../README_ja.md)

成果と制約を定義し、既存プロジェクト、マニフェスト、実ファイルを確認します。動く成果物を作り、実際のタスクに沿って検証します。測定は同じ入力と設定で繰り返し、成果と簡潔な根拠を渡します。Flowdesk はトレースと反復測定、オプションの事例は入力、計算、表計算、メモを示します。


1. 入力と成果物を指定
2. 実ファイルを確認
3. 成果物を実装
4. 同じ条件で検証
5. 成果と根拠を渡す
