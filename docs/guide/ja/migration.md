# M3 と Preview からの移行

[事例に戻る](../../../README_ja.md)

現在の公式文書の名称は MiniMax-M3.1-Flash です。手引き由来のプロンプトと記録では MiniMax-M3.1-Flash-Preview を保持し、新しい設定を更新します。思考を無効化する指定や none は削除します。OpenAI 互換では reasoning_content と最終回答の content を読み、reasoning_split=false は指定しません。ツール対話では完全な助手メッセージと対応する結果を保持します。
