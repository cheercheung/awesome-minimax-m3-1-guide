# Images et vidéo

[Retour aux cas](../../../README_fr.md)

Utilisez les images pour les références, mises en page et comparaisons, et la vidéo pour l’analyse temporelle. Conservez les fichiers et indiquez leur rôle. Pour découper un film, séparez analyse visuelle, transcription et tableau final. Le manuel emploie OpenCV, PyAV et faster-whisper. Le tableau précise quand une grande vidéo nécessite Files API.

| Entrée | Limite |
|---|---|
| Image | 10 MB |
| Vidéo par URL ou base64 | 50 MB |
| Corps de la requête | 64 MB |
| Vidéo via Files API | 512 MB |
