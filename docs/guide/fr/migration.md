# Migrer depuis M3 et Preview

[Retour aux cas](../../../README_fr.md)

La documentation actuelle utilise MiniMax-M3.1-Flash. Conservez MiniMax-M3.1-Flash-Preview dans les prompts et archives du manuel, et actualisez les nouvelles configurations. Retirez les demandes de désactivation du raisonnement ou la valeur none. Pour OpenAI, lisez reasoning_content et le texte final dans content ; ne demandez pas reasoning_split=false. Conservez les messages complets et les résultats des outils.
