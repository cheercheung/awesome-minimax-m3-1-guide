# Media and attribution

This collection uses the handbook supplied for the project and the linked public projects. Original source row hashes, attachment hashes, roles and available author information are retained in structured data. A handbook attribution and a public project link have distinct roles.

Selected media are hosted under the repository Cloudflare R2 namespace. Large screenshots have full-frame display renditions with preserved aspect ratio; original files remain linked in the asset manifest. Video renditions use H.264/AAC and preserve the complete sequence and original duration, with reviewed poster frames for README playback links. Original local file hashes and source metadata remain recorded. Input and reference videos are separate from output demos.

The supplied Prompt text stays in its original language. HTML line-break wrappers are decoded when extracting code blocks; source export escape characters remain as supplied. The original exported rows are preserved separately. Task summaries are not presented as original Prompts.

Third-party videos, images, prompts, software, product names and characters remain subject to their creators' rights. The editorial CC BY 4.0 license does not relicense these materials. To request attribution correction or removal, open an issue with the case ID and source
