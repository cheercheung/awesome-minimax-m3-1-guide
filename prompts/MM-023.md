# A terminal-style creative archive

[Source](../sources/handbook.md#mm-023) · [Case 23](../README.md#case-23)

```text
请设计并实现一个原创的创意工作室作品集网站，整体参考终端控制台式视觉和数字档案馆体验，网站采用纯黑、纯白和少量灰色作为唯一主色，使用高对比度、极简、冷静、技术化的视觉语言，搭配等宽字体、像素化字符、命令行提示、细线边框、文件路径、系统状态、加载进度、视频参数和类似服务器终端的文字信息，营造一个“打开创意工作室内部服务器，浏览视觉项目档案”的沉浸式体验；进入网站时先展示全屏黑底终端启动界面，依次出现 Console setup、网络配置、系统加载、项目读取和工作室信息，文字以逐行打印、光标闪烁和加载进度条的方式出现，完成后进入主页；主页采用类似文件浏览器的结构，顶部或左侧显示虚构路径，例如 C:\Studio\Home，设置 Home、Works、About、Studio、Contact 等导航，页面边角显示当前日期、时间、浏览器信息、系统状态和关闭按钮；首页主视觉展示一段全屏或大面积自动播放的创意影像，视频使用黑白或低饱和视觉，鼠标移动时显示坐标、视频编号和实时播放信息，视频区域可以响应悬停、点击、滚动和拖拽；Works 页面作为核心作品档案库，提供年份筛选、服务类型筛选和项目类别筛选，分类包括 3D、VFX、Motion、Edit、Color Grading、Commercial、Music Video、Short Film、Showreel 等，支持 List view 与 Grid view 两种浏览模式，列表模式显示编号、项目名称、年份和服务类型，网格模式展示作品缩略图、动态视频封面和悬停信息；用户悬停作品时，缩略图自动播放短视频预览，画面出现轻微黑白反转、扫描线、坐标标记或文件读取提示，点击后进入作品详情页，显示大尺寸视频播放器、项目标题、制作年份、服务类别、项目说明和原创技术信息，视频播放器下方模拟专业播放控制台，展示视频 ID、Viewport、Frames、Resolution、Current、Optimal Resolution、Volume、Codecs 等参数，但所有数据使用虚构内容；About 页面使用极简文字排版介绍工作室定位、团队、地点、服务范围和联系方式，Studio 页面展示工作空间图片、工作流程和制作能力，页面切换时通过终端清屏、字符重排、文件夹展开、黑白遮罩和横向滑动完成，不使用普通网站常见的淡入淡出卡片动画；网站整体交互要保持“系统读取—文件浏览—作品筛选—视频预览—项目展开”的清晰逻辑，鼠标光标可以设计成细小十字、终端箭头或像素光标，按钮采用文字链接和极细边框，不使用圆角卡片、渐变按钮、玻璃拟态、彩色装饰或复杂 HUD；技术栈使用 Next.js、React、TypeScript 和 Tailwind CSS 构建页面结构与响应式布局，使用 CSS Modules 或原生 CSS 实现黑白终端风格、等宽字体、像素字符、扫描线、闪烁光标和文件管理器式排版，使用 GSAP 或 Framer Motion 制作启动加载、文字逐行打印、页面切换、滚动平移、作品悬停和视频展开动画，使用 Lenis 实现顺滑滚动，使用原生 HTML5 Video 或 Video.js 实现作品视频播放、自动预览、静音切换和播放进度控制，使用 Zustand 管理当前页面、筛选条件、列表／网格视图、视频状态和作品详情，使用 HTML Canvas 制作轻微 CRT 扫描线、噪点、字符闪烁和终端光标效果，使用 Intersection Observer 和懒加载机制优化大量视频缩略图，使用 LocalStorage 保存用户的视图模式与筛选状态；网站需要适配桌面端、平板和移动端，在小屏设备上将侧边导航转化为折叠式终端菜单，保留黑白高对比、终端档案、作品浏览和视频交互这几个核心特征，最终呈现一个像创意后期工作室内部系统一样专业、克制、神秘、技术化且具有电影制作感的原创作品集网站。
```
