# A GTA-style personality quiz

[Source](../sources/handbook.md#mm-021) · [Case 21](../README.md#case-21)

```text
我想做一个 GTA 风格的沉浸式趣味人格测试网页，叫《测测你是 GTA 里的谁》。
请直接制作完整可运行的项目。整个体验要有经典 GTA 的游戏感：复古低模场景、电影感光线、厚重标题、任务标记、小地图和游戏菜单。核心是一个约3分钟、12道题的身份测试，不需要用户了解GTA剧情也能玩。
完整流程：
开场视频 → 标题主菜单 → 第一人称安全屋醒来 → 探索房间 → 走到 IDENTITY CHECK，按E进入答题 → 完成12题 → 获得角色结果 → 身份确认、原创彩蛋和分享。
具体要求：
1. 开场
使用我提供的Intro视频，前约5秒主要展示画面，随后依次渐显GTA风格标题、说明和“开始测试”按钮。点击开始后进入房间。有答题进度时提供继续入口。
2. 第一人称房间
玩家缓慢睁眼，在一个可移动、可环视的低模安全屋中醒来。房间里有桌椅、百叶窗、吊扇、旧电视、收音机和地图等细节。支持WASD移动、拖动环视，手机提供触控操作。
桌边放置IDENTITY CHECK标记，靠近后按E直接开始问卷。全程不显示手臂，不做拿起纸张或手持问卷动画。
3. 答题
固定12道生活情境题，每题4个选项。
每题配对应的第一视角视频，必须真实播放，不能用静态图片缩放冒充动态。保留场景声音，例如电台题有电台声，街景有城市环境声。视频结束后停在最后一帧，用户可以慢慢答。
支持上一题、修改答案、保存进度和重新测试。
4. 角色结果
结果包含Michael、Franklin、Trevor、CJ、Niko、Tommy、Lamar、Lester八位角色。
所有题目参与计分，同一套答案稳定得到相同结果，八种结果均可获得；最高分并列时讲清楚。
结果页展示人物海报、准确的原作简介、一句有记忆点的判词、性格标签，以及根据实际答案写出的趣味解读。
原作人物资料、趣味解读和我们原创的彩蛋任务要明确区分。
5. 音乐和语言
使用我提供的BGM，首页、房间、答题和结果之间连续播放，切换页面不能重头播放或叠音。
默认英文，支持中文切换，题目、结果、按钮和分享内容全部同步。遵循浏览器声音播放限制，在首次正常交互时启动音频。
6. 分享与交付
支持保存人物结果PNG、复制分享文字、下载答题摘要。桌面和手机都能完整操作。
优先接入我提供的视频、音乐、标题和人物素材，保持统一画风。
交付完整源代码、素材、README、本地启动脚本和可部署ZIP，核心功能无需API Key或外部CDN。
请实际完成并检查完整流程，明确说明未完成的验证。
```
