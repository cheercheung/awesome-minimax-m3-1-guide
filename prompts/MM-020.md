````text
H3 2K 视频与完整 UI 执行指令

## 1. 先理解我的资料，再生成网站
### 1.1 输入方式
我可以同时或分批提供以下任意资料：
- 品牌：名称、Logo、口号、品牌色、已有VI或字体。
- 业务：行业、产品、服务、核心卖点、目标受众、希望访客完成的动作。
- 文案：介绍、标题、产品说明、人物介绍、服务流程、已确认的经营信息。
- 图片：空间、产品、人物肖像、全身照、细节、包装、品牌图形。
- 视频：已有品牌片、场景片、人物片、动作片、产品演示。
- 联系信息：地址、电话、营业时间、邮箱、二维码、地图、预约或购买链接。

如果我还没上传任何资料，先用一次简洁回复请我提供“做什么品牌/业务、主要给谁看、希望访客做什么”，并说明Logo、图片、人物和已有文案均可直接上传。此时可以搭建中性的技术骨架，但不要替我虚构一个正式品牌。
### 1.2 资料清单与缺口
建立source-inventory.json，为每个文件记录：文件名、类型、实际内容、适用章节、可否直接使用、是否需要裁切/修复/制作视频、关联人物或产品、需要保留的限制。视频记录实际尺寸、时长、是否可解码；没有读取成功的文件明确标记。
明确区分：用户提供的事实、用户素材直接体现的信息、你提出的文案建议、仍缺失的信息。未知地址、电话、价格、资质、成绩、营业时间、客户评价、产品参数不得编造。
我明确要求保留原文的内容，只调整排版；其他文案可以在保持事实的前提下精简成适合网站阅读的表达。原始文件保留，另存处理后的资产。
仅在缺失信息会改变网站核心方向或使主要转化入口无法成立时，集中问必要问题，并继续不受影响的工作。非必要信息先隐藏对应字段。不要反复向我确认已经提供的事实。
## 2. 固定的体验标准与可替换内容
网站默认采用连续纵向滚动的章节结构。以全屏或接近全屏的真实视频、清晰的大标题、滚动中的画框变化和克制的操作建立质感。
以下由我的资料决定：品牌名、Logo、行业、人物、产品、场景、主题颜色、文案、分类、联系信息和主要CTA。
以下作为固定的体验标准保留：
1. 桌面使用CSS sticky舞台与GSAP/ScrollTrigger组合，按滚动进度控制缩放、位置、圆角和裁切。
2. 视频按正常时间线独立播放；停止滚动仍继续播放，暂停视频不影响滚动动效。
3. 每章有明确主题，画面和文字准确对应，不用同一段总片贯穿全部内容。
4. 大标题与画框分层，标题不是写进视频里的字幕；按钮与联系信息使用真实HTML。
5. 人物或重点对象的卡片桌面并列，手机纵向展示，不把三张卡缩成细条。
6. 最后一章用清晰、居中的品牌与行动卡收束，不堆砌空字段和重复口号。
7. 新生成的视频必须真实调用H3 2K，并接入真实成片。不能用静图动画冒充视频，也不能声称调用了实际上不可用的工具。
默认采用黑白、暖白和自然影像的视觉系统；我上传了明确品牌色或VI时，调整颜色和品牌图形，保留留白、字级、画框运动和操作的克制程度。
## 3. 将内容编排成完整的章节叙事
优先按以下八章组织，每章完成一个信息任务。章节名称、标题和素材必须来自我的业务，表中的行业示例只是映射方法，不是要出现在网站里的固定文字。
|章节|访客需要理解什么|可使用的内容|版式与动效|
|---|---|---|---|
|01 品牌开场|这是什么，为什么值得看|品牌定位、最核心场景/产品、一句主张|完整主视觉，大标题，shrink|
|02 场景与品质|品牌提供怎样的体验|空间、环境、材料、工艺、使用情境|主视频＋2个左右主题切换，expand|
|03 产品/服务选择|具体可以选择什么|产品系列、服务类型、设备或业务分类|主播放器＋文字选项，focus|
|04 真实过程与氛围|实际体验是什么样|使用过程、制作过程、活动、协作或日常|窄幅裁切展开，reveal|
|05 关键人物/重点对象|谁或什么构成核心价值|团队、创作者、代表产品或重点案例|3张左右独立动态卡，coaches模式用于卡片动画|
|06 解决方案|如何满足我的需求|服务方法、方案、定制、配套与支持|一段主题视频＋短说明，shrink|
|07 行动邀请|接下来可以怎样参与|到店、体验、咨询、预约、购买、观看完整作品|主视觉展开，expand|
|08 联系与转化|在哪里、如何联系或行动|品牌组合、真实信息和主要入口|居中暖白品牌卡，footer|
“coaches”只是动画模式的内部标识，不要求网站必须有教练。我的资料是产品品牌时，第5章可以是3件代表产品；是工作室时可以是3位创作者；没有对应内容时选择资料中真实存在的重点对象，不编造人物。
默认八章，但内容不足时先判断是否可通过真实资料组织出八个有效主题。如果必须合并，保留开场、产品/服务核心、行动收束和动效节奏，说明合并原因；不复制段落、不堆空白、不用不存在的业务硬凑章节。章节编号总数和导航根据最终实际数量生成。
每章标题尽量简短、具体，中文通常约8–18字；开场可用2–3个短句；正文1–2句。长介绍通过层级安排，不能把一段文档原封不动塞进视频中央。品牌正式长文需要保留时，可用展开区域，但必须真实可读。
CTA使用明确动词，如查看系列、认识团队、了解服务、预约体验。每个按钮必须有真实目的地。没有预约系统就跳转到真实联系区域，不制造“预约成功”。
## 4. UI视觉规范：具体实现到数值
### 4.1 颜色与影像
默认颜色：页面#101214，视频画框#171a1e，卡片#20262c，页脚#0b0d0f；主标题白色；末章卡#f6f5f1，文字#16191b，重点文字#050506。次级信息通过透明度区分。
以用户上传的空间、产品和人物建立统一影像语言。没有现场照片时可生成概念场景，但不要把生成画面宣称为真实门店实拍。自然、可信、干净的商业摄影感为默认方向；用户已有明确风格时沿用其风格。
画面主体完整，先用大景/完整产品交代，再以中景或动作补充。每段应增加新信息，不用手、水杯、墙角、纹理碎片替代核心内容。视频色调、光线、人物和材质统一。
视频遮罩只做可读性支持：顶部黑色30%，到40%位置透明，底部黑色48%。不把画面全压黑，不添加无关粒子、霓虹、装饰性图表或满屏渐变。
### 4.2 字体、字级与排版
正文与英文默认Manrope；后备Arial、PingFang SC、Hiragino Sans GB、Microsoft YaHei、sans-serif。中文使用系统中文无衬线字体。小型导航与英文标签用JetBrains Mono或ui-monospace。
桌面章节标题：
```css
.zoom-title {
  position: absolute;
  z-index: 2;
  top: clamp(112px, 12.5svh, 170px);
  left: 6vw;
  right: 6vw;
  max-width: 13em;
  margin: 0;
  font-size: clamp(34px, 6vw, 86px);
  font-weight: 700;
  line-height: 1.08;
  transform-origin: left top;
}
```
1512px宽度下标题约86px，左留白约91px，顶部至少112px。短句用span分段，桌面自然横排、手机按语义换行；不要把一个固定br用于所有屏幕。
普通正文层left/right6vw、bottom5svh、max-width46em，字号clamp(15px,1.4vw,20px)，line-height1.6。标题与正文都是画框的同级元素，不能把整段正文随视频一起缩小。
避免孤字、孤立标点与挤压。标题太长时优先精简可改写的标题、按语义分行，不能用极小字体解决。
### 4.3 顶部固定栏
fixed top0，左右铺满，z-index40，padding12px clamp(16px,3vw,40px)，flex横排，gap16px。顶部背景由rgba(10,12,14,.86)渐变至透明。
左侧Logo显示高度约20px、宽自动，链接到开场；旁边放品牌小口号，10px、字距.22em、白色62%透明度。右侧放“暂停视频”按钮。
按钮初始aria-pressed=false，点击后文字改“继续视频”、aria-pressed=true。字体12px、padding8px 14px、1px白色38%边框、半透明黑底、blur8px。暂停态白底黑字。
页头容器pointer-events:none，实际按钮和链接pointer-events:auto，避免透明区域阻挡页面。
### 4.4 章节编号、导航与CTA
编号格式“01 / 08 · 品牌名”，普通章top68px、left6vw、12px、字距.1em，z-index4。手机top64px，末页编号改正常流居中。
桌面导航固定在right:clamp(8px,1.4vw,22px)、top50%、translateY(-50%)，z-index40，纵向gap8px。每项是编号＋短横线，说明在hover与focus-visible时出现。说明绝对定位在左侧，避免隐藏文字仍占宽度导致编号错位。横线14px→28px，过渡0.25秒。
普通CTA白底黑字、矩形、13px、padding10px 18px、margin-top12px；hover上移2px与轻阴影，0.2秒。不使用巨型胶囊按钮。
素材选择按钮12px、padding8px 13px，白色30%边框、半透明黑底、blur6px；未选中白色80%，选中白底黑字。组内gap8px、margin-top14px、允许换行，不堆一排重复缩略图。
### 4.5 人物或重点对象卡片
桌面3列，grid-template-columns:repeat(3,minmax(0,1fr))，gap24px。卡片区域inset:clamp(232px,26svh,320px) 6vw 21svh。卡片圆角14px，overflow:hidden，背景#20262c，视频cover。
名称位于左下，left16px、bottom18px，白字clamp(20px,2vw,30px)与柔和黑色阴影。切换按钮位于右上top/right12px，11px、padding6px 10px。姓名/品名与按钮分处两角。
人物卡按钮可为“看工作状态”“看训练动作”；产品卡可为“看使用演示”。按内容设定，不把内部素材标签直接给访客看。
卡片下说明桌面bottom4svh，flex横排、允许换行、gap18px；与卡片留开，不叠在姓名上。人物/产品主体的object-position按实际素材调整，不统一裁掉头部或产品关键部位。
### 4.6 最后一章
深色背景中居中一张暖白卡，所有内容单列居中。舞台relative、min-height100svh、height:auto、padding90px 6vw、grid居中、overflow:visible。无普通视频暗角。
卡片width:min(1100px,100%)，圆角16px，背景#f6f5f1；padding:clamp(32px,4.5vw,64px) clamp(24px,5vw,70px)；flex column、align-items:center、text-align:center；gap:clamp(14px,1.8vw,22px)。
顺序：小编号 → 品牌Logo/品牌组合 → 邀请标题 → 一句说明 → 已确认联系信息 → 主要CTA → 必要小字。
Logo或组合图最大宽约520px、高auto；用户Logo细长或竖长时按视觉面积调整，不能强行拉成固定比例。口号用真实HTML或SVG排版，不让图像模型生成文字。已有Logo优先使用；没有Logo时先做准确品牌字标，不能复制其他品牌标志。
邀请标题clamp(20px,1.8vw,27px)、weight500、letter-spacing:-.01em；正文14–16px、line-height1.8；联系区域最大620px；标签10px等宽、字距.14em；小字11px。
只展示已有信息。未知字段完全隐藏，不显示“待补充”五格表。卡片可随内容增长，不强制180/200svh，不追加第二个巨大口号结尾。主要CTA真实可用；外链新窗口时设置合适的rel。
## 5. 滚动实现：固定采用下面这套空间关系
普通章：
```text
section.zoom-scene[data-zoom-scene][data-motion]
└─ .zoom-stage
   ├─ .scene-number
   ├─ .zoom-frame[data-motion-frame]
   │  └─ .zoom-media-inner[data-motion-inner]
   │     └─ .video-surface[data-video-surface]
   │        └─ video[data-auto-video]
   ├─ .zoom-title[data-motion-title]
   └─ .zoom-copy[data-motion-copy]
      ├─ p
      ├─ .scene-choices[data-video-choices]（需要时）
      └─ a.cta
```
标题、编号、文案必须在画框外，作为舞台子元素。画框transform-origin:center；标题transform-origin:left top。第5章的deck也是舞台直接子元素，卡片带data-motion-card。
启用GSAP后给html加zoom-enhanced。桌面普通章/卡片章min-height180svh，舞台sticky、top0、height100svh、overflow:hidden；手机普通章155svh，卡片章与末章改自然流。
180svh是section总长度，实际sticky动画行程约80svh；155svh约55svh。不要再加一屏空占位，也不要叠加GSAP pin。不做整页滚轮劫持、强制scroll-snap或额外惯性滚动。
普通ScrollTrigger：trigger为section，start:'top top'、end:'bottom bottom'、scrub:true、ease:'none'、invalidateOnRefresh:true。向上滚动严格可逆。
|模式|桌面|手机|时间轴|
|---|---|---|---|
|shrink|框scale1→.68，圆角0→22；标题1→.58|框1→.88，圆角0→14；标题1→.82|框duration.85从0起；标题.7从0起|
|expand|框.68→1，圆角22→0；标题y24→0、opacity.65→1|框.88→1，圆角14→0；标题相同|框.85从0起；标题.5从.15起|
|focus|内部画面scale1.22→1，外框固定|内部1.1→1|duration1|
|reveal|左右clip inset43%→0，rotate-5deg→0|左右inset20%→0，rotate0|duration.85|
|coaches/卡片|卡片scale.85→1、y40→0、stagger.12|每卡.92→1、y24→0|桌面duration.65；手机每卡top90%→top40%|
|footer|框scale.96→1、y24→0、opacity.45→1|同桌面|top95%→top35%，duration1|
除手机卡片章与末章外，文案从y24、opacity.35变到y0、opacity1，duration.5，从时间轴.45开始。duration是滚动时间轴的相对长度，不是用户必须等待的秒数。
同版本GSAP/ScrollTrigger，推荐3.14.2；用matchMedia管理800px断点与prefers-reduced-motion。初始化幂等，销毁旧context；resize、字体ready和必要布局变化后合并到一帧refresh。GSAP失败时仍有可读静态页面。
滚动代码不能把比例赋给video.currentTime。视频播放模块只负责媒体，不操纵画框缩放。
## 6. H3 2K：实际生成流程，不能省略或暗中换模型
### 6.1 先核实工具能力
在执行环境中发现并读取真实的视频生成工具参数，确认H3模型、2K输出档位、时长、画幅、首帧/参考图数量、异步任务提交与查询方式。用真实schema字段调用，不自行发明API名、参数或任务结果。
新生成视频固定使用H3 2K。H3 Max、其他模型或较低分辨率不能被当成已满足本要求。若工具提供独立model与resolution字段，分别选择真实的H3标识与2K档；若以完整档位提供，使用该档位的实际标识。
工具不可用、无权限或无法输出要求规格时，说明具体缺口，继续内容整理、UI和可完成的图像工作；保留已可用的用户视频或封面，不静默换模型、不伪造MP4、不把planned标为generated。
用户上传的合格视频可以直接复用，不需要为形式上的“全生成”重做；明确记录来源。需要补充的动态必须真实调用H3 2K。
### 6.2 建立一致性基准
先从上传资料中选出能代表品牌的主场景、关键对象、人物脸部、全身比例与产品细节。必须看图确认用途，不能把所有图片一股脑送进每条任务。
- 同一人物：保持面部、发型、身材比例、服装与年龄特征；人物身份不跨片漂移。
- 同一产品：保持外形、比例、颜色、结构、材质和真实功能；Logo/包装字样优先用真实素材保留。
- 同一空间：建立建筑和主要物体的固定位置；换机位不能让设备、家具或入口随机换位。
- 没有全身图：先生成并核对与本人肖像一致的比例基准，再做全身动作；不要直接从一张脸猜出不稳定身体。
- 没有现场素材：根据业务制作统一概念环境基准，明确为概念影像，不能伪称真实实拍。
先完成少量内部校准：一个主场景、一位人物或一件产品、一条H3 2K短片。确认质感、空间和对象稳定，再扩展其余素材。用户已给出的风格要求优先，不要求用户为了继续工作额外找参考网站。

### 6.5 提交、查询、落盘和检查
按真实工具能力提交任务，保留任务ID；使用工具规定的状态查询或等待方式，按限额控制并发。成功返回后下载真实文件到项目内，不能只保存会过期的URL。
检查首帧、中间、尾帧与动作关键帧，必要时完整播放。核对人物与产品一致性、空间稳定、动作、清晰度、实际宽高、时长和可解码性。不合格片重新生成或修复，不能靠换封面遮盖视频错误。
视频从自身成片提取海报，海报与选中视频一一对应。普通场景与形象微动可循环，完整动作优先单次播放并提供重播。不要把动作倒放来伪造循环。
记录字段至少包括：id、章节、用途、参考文件及用途、完整prompt、实际模型/分辨率参数、任务ID、状态、原片路径、网站用片路径、海报、实际宽高/时长、检查结果。不得保存账号密码或密钥到项目清单。

## 7. 播放控制与交互，和滚动控制分开
video带id、data-auto-video、data-src、poster、data-loop、muted、playsinline、preload=none。初始使用真实海报，进入有效可见区后再赋src并播放，不一次性加载全站全部视频。
桌面最多同时播放3个、手机最多2个，按可见面积和优先级管理。建议22%可见面积阈值，并检查hidden、display、visibility、opacity和尺寸；aria-hidden不是视觉隐藏条件。离屏、后台或全局暂停时停止。
素材切换使用统一接口与data属性：
```html
<button type="button"
  data-video-target="scene-video-3"
  data-video-source="assets/videos/category-02.mp4"
  data-video-poster="assets/posters/category-02.jpg"
  data-video-loop="true"
  aria-pressed="false">由用户内容确定的分类名</button>
```
点击立即更新同一播放器的src、poster和loop，加载并在允许时播放；不要求再滚一下。标题、说明、选中态保持准确。每个分组只有一个选中项，切换不跳转到单独视频文件。
场景/形象片循环；动作片单次结束显示“重播视频”，从0开始。自动播放受阻显示“点击播放”；网络或解码失败保留海报并显示“重试播放”，重试清除失败状态并重新load。快速切换使用序号防止过期异步结果覆盖新状态。
全局暂停优先。暂停中切换可以更新媒体和封面但不能偷偷恢复；继续后仅可见媒体恢复。减少动态模式默认静态海报，允许手动播放时保留明确的手动状态，不能被下次可见性检测立刻暂停。
网站派生视频优先使用可解码MP4/H.264与faststart，按需压缩；原始H3 2K文件另存。不要把高码率母版全部塞进首屏。所有视频静音，不自动播放声音。
## 8. 手机与边界状态
统一断点800px，检查375/390px手机、768px平板、1440/1512px桌面及低高度横屏。
手机标题top:clamp(104px,13svh,150px)，字号clamp(30px,9vw,48px)，max-width:none；390px时约35.1px。短句按语义分行，仅短语is-short使用nowrap，长句正常换行。
普通说明区bottom6svh，padding12px，背景#1119、圆角8px。隐藏页头英文小口号，保留Logo与暂停按钮。
手机导航改底部横向居中条，bottom为12px加安全区，padding8px 12px，gap10px，半透明黑底、细边框、blur10px；隐藏标签，保留编号与6px小圆点。body预留底部空间与安全区，交互热区尽量至少44px，视觉符号保持精简。平台自动浮标不得覆盖导航和CTA。
卡片章取消sticky与固定高度，舞台relative、height:auto、overflow:visible、flex column、padding112px 20px 40px。标题order0、deck order1、文案order2。单列gap24px，卡片aspect-ratio3/4、min-height360px。每张卡独立滚动归位，空的背景占位不撑出间距。
手机联系卡padding26px 20px、gap14px；品牌组合图宽min(300px,84vw)且max-width100%；邀请标题clamp(17px,4.9vw,21px)，正文与联系信息13px、行高约1.7。
低高度桌面需要时让卡片章转自然流，确保标题、卡片、说明和CTA不叠压。不要用全局overflow:hidden掩盖被裁掉的内容。
减少动态时清除大幅transform/clip-path、关闭自动播放与sticky长行程；卡片章和联系章保持height:auto；无JS/GSAP失败也保留可读页面与原生锚点。
lang、页面title、description由实际内容生成；全页一个h1、后续h2；按钮type与aria-pressed准确；图片有合理alt；焦点可见；地址使用address并设置正常字形。直接进入任意chapter锚点及刷新后定位正确，浏览器前进后退可用。

### scroll-effects.js
```js
(function () {
  'use strict';
  let mediaContext = null;
  let rootElement = null;
  let layoutObserver = null;
  let refreshFrame = 0;
  function refresh() {
    if (refreshFrame) return;
    refreshFrame = requestAnimationFrame(function () {
      refreshFrame = 0;
      if (window.ScrollTrigger) window.ScrollTrigger.refresh();
    });
  }
  function destroy() {
    mediaContext?.revert();
    mediaContext = null;
    layoutObserver?.disconnect();
    layoutObserver = null;
    window.removeEventListener('resize', refresh);
    document.removeEventListener('toggle', refresh, true);
    if (refreshFrame) cancelAnimationFrame(refreshFrame);
    refreshFrame = 0;
    if (rootElement) rootElement.classList.remove('zoom-enhanced');
  }
  function init(root) {
    destroy();
    rootElement = root && root.nodeType !== 9 ? root : document.documentElement;
    const gsap = window.gsap;
    const ScrollTrigger = window.ScrollTrigger;
    if (!gsap || !ScrollTrigger) {
      console.warn('[SiteMotion] GSAP/ScrollTrigger unavailable; keeping ordinary readable layout.');
      return;
    }
    gsap.registerPlugin(ScrollTrigger);
    rootElement.classList.add('zoom-enhanced');
    mediaContext = gsap.matchMedia();
    mediaContext.add({
      desktop: '(min-width: 800px)',
      mobile: '(max-width: 799px)',
      compact: '(max-height: 650px)',
      reduced: '(prefers-reduced-motion: reduce)',
    }, function (context) {
      const mobile = context.conditions.mobile;
      const reduced = context.conditions.reduced;
      const scenes = rootElement.querySelectorAll('[data-zoom-scene]');
      scenes.forEach(function (scene) {
        const frame = scene.querySelector('[data-motion-frame]');
        const inner = scene.querySelector('[data-motion-inner]');
        const title = scene.querySelector('[data-motion-title]');
        const copy = scene.querySelector('[data-motion-copy]');
        const cards = scene.querySelectorAll('[data-motion-card]');
        const mode = scene.dataset.motion || 'expand';
        if (!frame) return;
        if (reduced) {
          gsap.set([frame, inner, title, copy, ...cards].filter(Boolean),
            { clearProps: 'transform,opacity,visibility,clipPath,borderRadius' });
          return;
        }
        if (mode === 'coaches' && (mobile || context.conditions.compact)) {
          cards.forEach(function (card) {
            gsap.fromTo(card, { scale: 0.92, y: 24 }, {
              scale: 1, y: 0, ease: 'none',
              scrollTrigger: { trigger: card, start: 'top 90%', end: 'top 40%', scrub: true, invalidateOnRefresh: true },
            });
          });
          return;
        }
        const tl = gsap.timeline({
          defaults: { ease: 'none' },
          scrollTrigger: {
            trigger: scene,
            start: mode === 'footer' ? 'top 95%' : 'top top',
            end: mode === 'footer' ? 'top 35%' : 'bottom bottom',
            scrub: true,
            invalidateOnRefresh: true,
          },
        });
        const insetScale = mobile ? 0.88 : 0.68;
        if (mode === 'shrink') {
          tl.fromTo(frame, { scale: 1, borderRadius: 0 },
            { scale: insetScale, borderRadius: mobile ? 14 : 22, duration: 0.85 }, 0);
          if (title) tl.fromTo(title, { scale: 1 }, { scale: mobile ? 0.82 : 0.58, duration: 0.7 }, 0);
        } else if (mode === 'reveal') {
          tl.fromTo(frame, { clipPath: mobile ? 'inset(0% 20% 0% 20%)' : 'inset(0% 43% 0% 43%)', rotate: mobile ? 0 : -5 },
            { clipPath: 'inset(0% 0% 0% 0%)', rotate: 0, duration: 0.85 }, 0);
        } else if (mode === 'focus') {
          if (inner) tl.fromTo(inner, { scale: mobile ? 1.1 : 1.22 }, { scale: 1, duration: 1 }, 0);
        } else if (mode === 'coaches') {
          gsap.set(cards, { scale: 0.85, y: 40 });
          tl.to(cards, { scale: 1, y: 0, stagger: 0.12, duration: 0.65 }, 0);
        } else if (mode === 'footer') {
          tl.fromTo(frame, { scale: 0.96, y: 24, opacity: 0.45 },
            { scale: 1, y: 0, opacity: 1, duration: 1 }, 0);
        } else {
          tl.fromTo(frame, { scale: insetScale, borderRadius: mobile ? 14 : 22 },
            { scale: 1, borderRadius: 0, duration: 0.85 }, 0);
          if (title) tl.fromTo(title, { y: 24, opacity: 0.65 }, { y: 0, opacity: 1, duration: 0.5 }, 0.15);
        }
        if (copy && mode !== 'footer') {
          tl.fromTo(copy, { y: 24, opacity: 0.35 }, { y: 0, opacity: 1, duration: 0.5 }, 0.45);
        }
      });
    });
    window.addEventListener('resize', refresh, { passive: true });
    document.addEventListener('toggle', refresh, true);
    document.fonts?.ready.then(refresh);
    if ('ResizeObserver' in window) {
      layoutObserver = new ResizeObserver(refresh);
      layoutObserver.observe(document.body);
    }
    refresh();
  }
  window.SiteMotion = { init: init, refresh: refresh, destroy: destroy };
})();

  function show(rec, state) {
    rec.state = state;
    rec.video.dataset.playbackState = state;
    const labels = { blocked: '点击播放', ended: '重播视频', error: '重试播放', reduced: '播放视频' };
    const label = labels[state] || '';
    if (rec.button.textContent !== label) rec.button.textContent = label;
    if (rec.button.hidden !== !label) rec.button.hidden = !label;
  }
  function visibleScore(rec) {
    const video = rec.video;
    if (!video.isConnected || video.closest('[hidden],[data-media-selected="false"]')) return 0;
    let opacity = 1;
    for (let el = video; el && el !== document.documentElement; el = el.parentElement) {
      const style = getComputedStyle(el);
      if (style.display === 'none' || style.visibility === 'hidden') return 0;
      opacity *= Number(style.opacity);
    }
    if (opacity < .05) return 0;
    const b = video.getBoundingClientRect();
    if (b.width <= 0 || b.height <= 0) return 0;
    const w = Math.max(0, Math.min(innerWidth, b.right) - Math.max(0, b.left));
    const h = Math.max(0, Math.min(innerHeight, b.bottom) - Math.max(0, b.top));
    const fraction = w * h / (b.width * b.height);
    if (fraction < .22) return 0;
    return fraction + Number(video.dataset.videoPriority || 0) * 10;
  }
  function ensureSource(rec) {
    if (rec.assigned) return true;
    const url = validURL(rec.video.dataset.src || rec.video.getAttribute('src'));
    if (!url) { rec.failed = true; show(rec, 'error'); return false; }
    rec.assigned = true;
    rec.video.src = url;
    rec.video.load();
    return true;
  }
  function pause(rec) {
    rec.wanted = false;
    rec.sequence += 1;
    rec.pending = false;
    rec.video.pause();
  }
  function play(rec) {
    if (destroyed || rec.failed || rec.blocked || rec.ended) return;
    if (!ensureSource(rec)) return;
    rec.wanted = true;
    if (rec.pending || !rec.video.paused) return;
    const sequence = ++rec.sequence;
    rec.pending = true;
    show(rec, 'loading');
    let result;
    try { result = rec.video.play(); } catch (error) { result = Promise.reject(error); }
    Promise.resolve(result).then(function () {
      if (destroyed || sequence !== rec.sequence) return;
      rec.pending = false;
      if (!rec.wanted) { rec.video.pause(); return; }
      show(rec, 'playing');
    }).catch(function (error) {
      if (destroyed || sequence !== rec.sequence) return;
      rec.pending = false;
      if (error?.name === 'AbortError') { show(rec, 'idle'); return; }
      rec.blocked = error?.name === 'NotAllowedError';
      rec.failed = !rec.blocked;
      show(rec, rec.blocked ? 'blocked' : 'error');
    });
  }
  function update() {
    raf = 0;
    if (destroyed) return;
    const candidates = [];
    records.forEach(function (rec) {
      const score = visibleScore(rec);
      if (!score) rec.manual = false;
      if (score && !rec.failed && !rec.blocked && !rec.ended && (!reduced.matches || rec.manual)) {
        candidates.push({ rec, score });
      } else if (score && reduced.matches && !rec.manual && !rec.failed && !rec.blocked && !rec.ended) {
        show(rec, 'reduced');
      }
    });
    candidates.sort((a, b) => b.score - a.score);
    const selected = pausedAll || document.hidden ? [] : candidates.slice(0, innerWidth < 800 ? 2 : 3);
    const active = new Set(selected.map(item => item.rec));
    records.forEach(function (rec) {
      if (active.has(rec)) play(rec);
      else if (!rec.video.paused || rec.pending) pause(rec);
    });
  }
  function schedule() {
    if (!destroyed && !raf) raf = requestAnimationFrame(update);
  }
  function manualPlay(rec) {
    if (pausedAll || document.hidden || !visibleScore(rec)) return;
    const ended = rec.ended || rec.video.ended;
    const failed = rec.failed;
    pause(rec);
    rec.manual = true;
    rec.failed = rec.blocked = rec.ended = false;
    if (failed) rec.assigned = false;
    if (!ensureSource(rec)) return;
    if (ended) { try { rec.video.currentTime = 0; } catch {} }
    // 在用户点击调用链内启动，保留浏览器手势授权。
    play(rec);
    schedule();
  }
  function register(video) {
    if (records.has(video)) return;
    video.muted = true;
    video.playsInline = true;
    video.autoplay = false;
    video.loop = video.dataset.loop !== 'false';
    video.preload = 'none';
    const shell = video.closest('[data-video-surface]') || video.parentElement;
    const button = document.createElement('button');
    button.type = 'button';
    button.className = 'video-play-fallback';
    button.hidden = true;
    shell.appendChild(button);
    const rec = { video, button, assigned: false, sequence: 0, pending: false,
      wanted: false, failed: false, blocked: false, ended: false, manual: false, events: [] };
    function on(event, fn) { video.addEventListener(event, fn); rec.events.push([event, fn]); }
    on('loadeddata', function () { video.dataset.videoReady = 'true'; schedule(); });
    on('playing', function () { show(rec, 'playing'); });
    on('error', function () { rec.failed = true; show(rec, 'error'); });
    on('ended', function () {
      if (!video.loop) { rec.ended = true; show(rec, 'ended'); schedule(); }
    });
    rec.click = () => manualPlay(rec);
    button.addEventListener('click', rec.click);
    records.set(video, rec);
    observer?.observe(video);
    if (reduced.matches) show(rec, 'reduced');
  }
  function remove(rec) {
    pause(rec);
    observer?.unobserve(rec.video);
    rec.events.forEach(([event, fn]) => rec.video.removeEventListener(event, fn));
    rec.button.removeEventListener('click', rec.click);
    rec.button.remove();
    records.delete(rec.video);
  }
  function discover() {
    root.querySelectorAll('video[data-auto-video]').forEach(register);
    records.forEach(rec => { if (!rec.video.isConnected) remove(rec); });
    schedule();
  }
  function destroy() {
    destroyed = true;
    cancelAnimationFrame(raf); raf = 0;
    mutations?.disconnect(); observer?.disconnect();
    records.forEach(remove);
    window.removeEventListener('scroll', schedule);
    window.removeEventListener('resize', schedule);
    document.removeEventListener('visibilitychange', schedule);
    reduced.removeEventListener('change', schedule);
  }
  function init(container = document) {
    destroy(); root = container; pausedAll = false; destroyed = false;
    observer = new IntersectionObserver(schedule, { threshold: [0, .22, .5, .8, 1] });
    discover();
    mutations = new MutationObserver(discover);
    mutations.observe(root === document ? document.body : root, {
      childList: true, subtree: true, attributes: true,
      attributeFilter: ['hidden', 'data-media-selected']
    });
    window.addEventListener('scroll', schedule, { passive: true });
    window.addEventListener('resize', schedule, { passive: true });
    document.addEventListener('visibilitychange', schedule);
    reduced.addEventListener('change', schedule);
  }
  function setSource(video, source) {
    const rec = records.get(video);
    const url = validURL(source.src);
    if (!rec || !url) throw new Error('播放器或媒体路径无效');
    pause(rec);
    rec.failed = rec.blocked = rec.ended = rec.assigned = false;
    rec.manual = false;
    delete video.dataset.videoReady;
    video.dataset.src = url;
    video.poster = source.poster || '';
    video.loop = source.loop !== false;
    video.dataset.loop = String(video.loop);
    show(rec, reduced.matches ? 'reduced' : 'idle');
    // 全局暂停时清掉旧片，保持新封面；继续后再加载。
    video.removeAttribute('src'); video.load();
    if (!pausedAll && !document.hidden && visibleScore(rec) && !reduced.matches) play(rec);
    schedule();
  }
  window.SiteMedia = {
    init, destroy, refresh: discover, setSource,
    setPaused(value) {
      pausedAll = Boolean(value);
      if (pausedAll) records.forEach(pause);
      schedule();
    }
  };
})();

(function () {
  'use strict';
  let cleanup = null;
  function init() {
    cleanup?.();
    window.SiteMotion?.init();
    window.SiteMedia?.init();
    const reduced = matchMedia('(prefers-reduced-motion: reduce)');
    const toggle = document.querySelector('[data-video-pause-all]');
    let paused = false, closed = false, hashFrame = 0;
    function togglePause() {
      paused = !paused;
      window.SiteMedia?.setPaused(paused);
      toggle?.setAttribute('aria-pressed', String(paused));
      if (toggle) toggle.textContent = paused ? '继续视频' : '暂停视频';
    }
    function alignHash() {
      cancelAnimationFrame(hashFrame);
      if (closed || !location.hash) return;
      let id = '';
      try { id = decodeURIComponent(location.hash.slice(1)); } catch { return; }
      const target = document.getElementById(id);
      if (!target) return;
      hashFrame = requestAnimationFrame(() => {
        hashFrame = requestAnimationFrame(() => {
          if (!closed) target.scrollIntoView({ block: 'start', behavior: 'auto' });
        });
      });
    }
    function click(event) {
      const element = event.target instanceof Element ? event.target : null;
      const button = element?.closest('[data-video-source]');
      if (button) {
        const video = document.getElementById(button.dataset.videoTarget || '');
        if (!video || !window.SiteMedia) return;
        try {
          window.SiteMedia.setSource(video, {
            src: button.dataset.videoSource,
            poster: button.dataset.videoPoster,
            loop: button.dataset.videoLoop !== 'false'
          });
          button.closest('[data-video-choices]')?.querySelectorAll('[data-video-source]').forEach(item => {
            item.setAttribute('aria-pressed', String(item === button));
          });
        } catch (error) { console.warn(error.message); }
        return;
      }
      const link = element?.closest('[data-scroll-to-end]');
      if (!link || event.ctrlKey || event.metaKey || event.shiftKey || event.altKey) return;
      const target = document.getElementById(link.dataset.scrollToEnd || '');
      if (!target) return;
      event.preventDefault();
      target.scrollIntoView({ behavior: reduced.matches ? 'auto' : 'smooth', block: 'start' });
      if (location.hash !== '#' + target.id) history.pushState(null, '', '#' + target.id);
    }
    if (toggle) {
      toggle.textContent = '暂停视频';
      toggle.setAttribute('aria-pressed', 'false');
      toggle.addEventListener('click', togglePause);
    }
    document.addEventListener('click', click);
    window.addEventListener('hashchange', alignHash);
    window.addEventListener('popstate', alignHash);
    alignHash();
    // 用户开始浏览后不因字体晚到而把页面突然拉回锚点。
    let userMoved = false;
    const moved = () => { userMoved = true; };
    window.addEventListener('wheel', moved, { passive: true, once: true });
    window.addEventListener('touchstart', moved, { passive: true, once: true });
    document.fonts?.ready.then(() => { if (!closed && !userMoved) alignHash(); });
    cleanup = function () {
      closed = true; cancelAnimationFrame(hashFrame);
      toggle?.removeEventListener('click', togglePause);
      document.removeEventListener('click', click);
      window.removeEventListener('hashchange', alignHash);
      window.removeEventListener('popstate', alignHash);
      window.removeEventListener('wheel', moved);
      window.removeEventListener('touchstart', moved);
      window.SiteMedia?.destroy();
      window.SiteMotion?.destroy();
    };
  }
  window.SiteApp = { init, destroy: () => cleanup?.() };
  if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', init, { once: true });
  else init();
})();
````
