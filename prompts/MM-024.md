# A Windows XP browser desktop

[Source](../sources/handbook.md#mm-024) · [Case 24](../README.md#case-24)

```text
请从零创建一个完整、可直接运行的浏览器桌面作品：
《Windows XP · 2005 / 放学后的电脑》
直接完成项目、运行并检查，最终交付可打开、可交互的成品。
目标体验：像打开了 2005 年家里的 Windows XP 电脑，可以在不同应用间切换、聊模拟 QQ、听怀旧歌曲、看 MV、画画、保存文件，以及在 XP 窗口里直接玩 GTA《罪恶都市》视觉风格的原创 3D 城市小游戏。
不要向我提问，不要只给教程、方案或零散代码。自行完成合理的实现选择。所有核心交互都要真实实现，不留 TODO、空按钮、假进度条和“后续接入”入口。先保证 XP 仿真度、GTA 游戏、QQ、播放器四个核心，再完成其余应用。
1. 整体视觉与首次打开
系统外壳严格采用中文 Windows XP 的 Luna 蓝色主题。默认是蓝天、白云、绿色丘陵壁纸，图标纵向排在左侧，底部是固定 30px 高的蓝色任务栏。桌面必须铺满浏览器，不出现网页式顶栏、产品介绍、卡片式导航和营销按钮。
参考桌面尺寸为 1440×900，同时适配 1280×720 和较小窗口。使用 Tahoma、宋体、Microsoft YaHei 的字体回退，普通界面文字 11—13px。窗口采用 2—3px 蓝边、约 29px 标题栏、小圆角、亮蓝渐变、细高光与轻阴影。窗口内底色 #ECE9D8，输入框有经典凹陷边框；关闭按钮红橙渐变；开始按钮绿色渐变、白色“开始”字样。不要把复古界面改成现代大圆角、毛玻璃和宽松卡片。
图标以 32×32px 的旧系统风格为主，保留清晰轮廓和少量像素感；不要用一组系统 Emoji 充当全部桌面图标。音效短促、轻量，提供全局静音；首次播放声音必须来自用户操作。
首次进入显示简短的 XP 风格欢迎界面，提供“进入桌面”按钮；进入后默认没有应用遮挡桌面。右下角显示真实本地时间。桌面图标固定为：我的电脑、我的文档、回收站、Internet Explorer、QQ2005、千千静听、画图、记事本、扫雷、蜘蛛纸牌、罪城海岸。
2. 真正工作的窗口系统
所有应用共用一个窗口管理器：支持拖动、边缘缩放、最小化、最大化、还原、关闭、活动窗口层级、非活动标题栏与任务栏按钮。双击标题栏可最大化；点击任务栏可恢复最小化窗口。最大化区域必须避开任务栏；窗口不能被拖到完全找不回的位置。
实现开始菜单、桌面右键菜单、图标选择、双击打开、重命名、删除、刷新和显示属性。开始菜单包含常用应用、所有程序、我的文档、控制面板、注销和关闭计算机。关机是可返回的模拟关机画面。
菜单、弹窗、文件列表、保存对话框也必须使用 XP 风格。拖动和缩放使用 Pointer Events，正确处理 pointer capture。关闭窗口时释放定时器、事件、音视频和 WebGL 资源。
3. 统一的文件与设置
记事本、画图、我的文档、回收站使用同一套文件数据。每个文件有稳定 ID、名称、类型、内容、创建时间、修改时间和删除状态。文件不能只存在于某个应用的临时变量里。
必须跑通：新建文字或绘画 → 保存到我的文档 → 关闭应用 → 从文件夹重新打开 → 修改并再次保存 → 关闭并重新打开窗口后仍存在。支持重命名、删除到回收站、还原和导出 TXT / PNG。
文件、设置、图片与聊天记录必须在同一页面会话内跨窗口和应用保留。可尝试 localStorage 或 IndexedDB 保存，但存储不可用时使用共享内存状态，仍能完整操作；不要求刷新页面后恢复。导入的图片和本机音视频在浏览器中处理，不上传到服务器。捕获存储失败并给出简短提示，不能在保存失败后显示成功。
4. GTA 视觉的原创 3D 游戏：VICE COAST / 罪城海岸
双击游戏图标，在 XP 应用窗口内进入游戏，也可切换全屏。玩家点击“进入城市”即可游玩，不需要游戏安装包、ROM、原版资源文件、注册、API Key 或额外配置。游戏使用项目自带的原创地图和模型，不以原版《罪恶都市》移植版的身份宣传。
整个游戏内容都要呈现 GTA《罪恶都市》及 PS2 时代城市游戏的视觉语言：
开场是一张高完成度漫画拼贴封面：粗黑轮廓、硬边色块、青绿衬衫人物、复古跑车、棕榈树、海岸旅馆与直升机剪影。标题用厚重白字、黑描边，搭配粉色斜体 Vice Coast。可以生成本地插画，或制作完整的原创 SVG 插画，不用几个方块充当封面。
场景是热带海滨城市的傍晚：粉紫天空、橘色夕阳、青蓝海水、淡紫远景雾，建筑采用奶油白、薄荷绿、浅粉色和暖黄色。棕榈长街、沙滩、Art Deco 旅馆、停车场、咖啡店、加油站和霓虹招牌形成清楚的区域差异。
采用有设计的低多边形模型、清晰的大色块与适量旧贴图质感。人物比例接近真实成年人，有头发、脸部朝向、青绿短袖、牛仔裤和鞋子；车辆有车身、车窗、轮胎、车灯和驾驶方向，敞篷跑车是默认可驾驶车辆。
摄像机是第三人称追尾视角，走路和驾驶都有平滑跟随、转向惯性和合理高度。允许鼠标拖动环视及 C 键切换视角。避免镜头钻进地面或建筑。
右上角显示时间、绿色现金、粉色体力条和六颗追捕星；左下角是带边框的圆形雷达；右下角是时速与车辆名称。任务标题使用黄色或粉色描边文字，取送点是粉色发光圆柱。HUD 要像老游戏的屏幕信息，保持紧凑，给城市画面留空间。
城市至少有 12 个可辨认街区、一条连续滨海道路、多条连通支路、可走的沙滩、可驾驶车辆、道路交通与少量行人。模型可以程序化生成，但建筑不能全部相同。地图、雷达、道路导航、碰撞体和任务点必须使用同一套世界坐标。
真实玩法：
WASD / 方向键移动或驾驶，Shift 奔跑；E 在车辆附近上下车，在任务圈内接取或交接任务；Space 手刹；C 切换视角；P / Esc 暂停；M 静音；F 全屏；R 回到旅馆。
人物有走路与跑步的肢体摆动。车有加速、倒车、惯性、转向、阻尼与制动，转向与速度相关，不能把驾驶实现成平移盒子。
建筑、路缘、车辆和地图边界具有碰撞。车辆不能穿墙，上下车要选择安全落点，玩家掉出地图时能恢复。
撞击车辆或路障会提升追捕等级。警车沿道路追踪玩家，使用基础路网寻路；离开追踪范围一段时间后星级逐步下降。
制作至少三段真实的限时“磁带送达”任务：前往咖啡店取件 → 驾车送至海边旅馆 → 再送往另一处街区。要有明确的取件、在途、送达、失败、重试状态。完成奖励现金并开启下一段；倒计时不能在暂停时继续流失。
保存现金、已完成任务数和音效设置。发动机音高随车速改变，碰撞和警笛有声音反馈。
游戏运行必须是实时 3D，不用视频、静态背景或预渲染动画代替可探索城市。移动端显示方向键、交互键和刹车键。窗口失去焦点或最小化时暂停游戏，并清空按键状态，避免恢复后角色持续移动。
5. QQ2005：细节丰富的怀旧聊天模拟
QQ 主面板默认约 310×560px，窄长比例，浅蓝渐变、企鹅图标、个人头像、昵称、个性签名、太阳/月亮/星星等级、在线状态、好友搜索、分组列表和底部工具栏都要完整。
设置 12 位各有头像、昵称、状态、签名与说话习惯的虚构好友，分成“我的好友”“同学”“网友”三个好友分组；另设三个可打开的模拟群：“初三（2）班”“周末网吧集合”“华语流行音乐”。包含在线、离开、忙碌、隐身、离线状态；分组可折叠，离线头像灰化。
昵称和签名带有适量千禧年网络文化，例如“夏天的风”“蓝色耳机”“正在输入…”“放学别走，等我一下”。不要让每个人都说同一句网络热梗。
聊天窗口必须包括对方头像与签名、工具栏、带时间的消息记录、输入框、发送按钮、字体颜色/字号、表情面板、图片发送、聊天记录查看与导出。提供约 60 个复古小黄脸表情，统一视觉，不依赖当前操作系统 Emoji 的外观。
用户消息立即出现在记录中；对方先显示“正在输入”，再根据角色与关键词给出自然的本地预设回复。支持“作业”“放学”“游戏”“音乐”“在吗”等话题，每类有多个变体，避免连续重复。对话围绕普通的放学生活、QQ 空间、听歌与游戏展开，不接真实 QQ，不发送消息给现实用户。
支持窗口抖动、未读数字、任务栏闪烁和短消息提示音。窗口抖动幅度小且短，避免反复轰炸。修改自己的昵称、头像、签名和状态后，相关窗口同步更新，在同一页面会话内关闭并重新打开应用后保留。聊天记录可尝试持久化，失败时使用内存状态。
QQ 空间也能打开：包含个人资料、两篇可编辑日志、相册、留言板和音乐盒；米黄与浅金色旧博客视觉。可以编辑心情、写留言，音乐盒歌曲点击后在千千静听中定位并播放对应曲目。只在“关于”里简短说明为本地模拟，不在聊天界面铺满技术说明。
6. 千千静听：35 首怀旧歌曲与 MV
播放器默认约 780×540px，银灰金属渐变外壳、青绿色 LCD、数字时间、跳动频谱、细进度条、实体感小按钮。提供银色、粉色、深蓝三种皮肤。
上部是歌曲名、歌手、年代、实际媒体类型和播放状态；中间是上一首、播放、暂停、停止、下一首、循环模式、音量；下部左侧约 40% 宽度为歌单，右侧约 60% 为可见的视频区域。歌单工具包括搜索、分类、收藏星标、“＋ 音乐 / MV”和换肤。
未播放时显示小巧的金属唱片、歌曲名、歌手和普通“▶ 播放”按钮。不要出现“连接官方 MV”、YouTube 字样、来源栏、“打开原页面”按钮、外部网站导航或大段网络实现说明。播放 MV 时直接使用右侧区域，操作由复古播放器的控件统一控制。
在线内容可使用官方允许嵌入的播放器与 API；这是实现层的选型，不是产品文案。使用其支持的精简控制参数，不要用裁切、遮罩、覆盖层或隐藏 iframe 去抹掉第三方播放器必须保留的标识。不要承诺能完全隐藏视频自身的原生角标。MV 区域必须完整可见，尺寸满足平台要求。若使用 YouTube IFrame API，可从 controls:0、playsinline:1、rel:0、autoplay:0 开始配置，在用户点击后播放；自行核对当前官方参数。

7. 其他应用必须能用
记事本：编辑、新建、打开、保存、另存为、导出、未保存修改提醒。
画图：铅笔、画笔、橡皮、填充、直线、矩形、椭圆、颜色盘、线宽、撤销/重做、导入图片、保存与导出 PNG。画好的图片可设成桌面壁纸。
我的电脑 / 我的文档：经典工具栏、地址栏、侧边任务区、文件列表和属性。回收站支持查看、还原、永久删除与清空确认。
扫雷：至少初级 9×9 / 10 雷与中级 16×16 / 40 雷；首击安全、空白扩展、插旗、计时、胜负和重新开始。
蜘蛛纸牌：单花色的真实规则，降序移动、合法整组拖动、K 到 A 完成收牌、发牌、撤销、胜负判断；保证牌数守恒。
计算器：数字、四则运算、小数、百分比、退格、清除和连续计算。
Internet Explorer：仿真浏览器外壳与自带的 2005 导航主页；站内内容正常打开，第三方网站无法嵌入时明确使用新标签页，不伪装加载成功。
8. 工程、运行与性能
优先使用原生 HTML、CSS、JavaScript ES Modules，加本地 Three.js。将窗口管理、文件系统、QQ、播放器、各工具和游戏拆成清晰模块。游戏可通过同源 iframe 独立运行，键盘输入只在游戏获得焦点时生效，QQ 输入和记事本输入不能同时控制车辆。
项目必须能静态托管，使用正确的相对资源路径，无需后端、付费 API、账号或密钥。核心字体、图标、壁纸、游戏插画、模型和 Three.js 随项目提供，运行时不依赖外部 CDN 拉取核心资源。外部音乐与核心桌面加载彼此独立，一首 MV 加载失败不能拖垮系统。
```
